## Codebase Understanding

### Architecture Overview

NutriSnap AI 是单文件 Flask 后端（app.py, ~1300行）+ 单页面前端（templates/index.html, ~4400行）架构。前端使用 Tailwind CSS CDN + Chart.js CDN + 原生 JS，无构建工具。后端使用 Google Gemini / OpenRouter 双 AI 引擎，SQLite 存储。v5 采用 Local-First 架构：食物/运动/聊天记录存 localStorage，仅每日汇总同步服务器。本地开发 `python app.py` → :5000，Flask debug 自动重载。部署通过 GitHub Actions 自动触发 Cloud Run + Android APK 构建。

### Key Patterns Discovered

- **safeFetchJSON(url, options)** — 封装 fetch，自动检查 response.ok + Content-Type: application/json，非 JSON 时抛错
- **readNumberField(id, options)** — 统一输入校验，先正则验证格式 `(/^\d+$/)` / `(/^\d+(\.\d+)?$/)`，再 Number() + min/max 范围检查
- **withActionLock(key, btn, work)** — 防重锁：设置 actionLocks Set + 禁用按钮 + 300ms 延迟释放
- **showToast(msg, type)** — 全局提示（success/error/info）
- **getAuthHeaders()** — 返回 `{ X-User-Id: username }`
- **isLocalMode()** — 判断是否本地模式（无用户登录时）
- 前端 JS 中所有中文字符串均用 `\uXXXX` Unicode 编码防止乱码
